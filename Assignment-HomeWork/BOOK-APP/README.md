# 📚 Book Project

A modern book management web application built with **React.js** that allows users to browse and manage books. The project focuses on React fundamentals, state management with **Zustand**, routing, hooks, and responsive UI development using **Tailwind CSS**.

## 📌 Project Overview

Book Project is a React-based application where users can explore books through a clean and responsive interface. The application demonstrates modern frontend development practices using reusable components and global state management.

This project was developed as part of my **Summer Training (MERN + Generative AI)**.

## 🚀 Features

- 📖 Browse Books
- 🔍 Search Books
- ❤️ Add & Remove Favorites
- 🌙 Light/Dark Theme
- 📱 Fully Responsive Design
- ⚡ Global State Management with Zustand
- 🧭 Multi-page Navigation with React Router
- 🎨 Modern UI built with Tailwind CSS
